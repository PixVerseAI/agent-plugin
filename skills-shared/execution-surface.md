# Choose The Execution Surface

Use the matching creative Skill directly for images, video clips, music, speech, templates
or scripts. For multi-scene production, Canvas, editing, captions or timed assembly,
explain the scope before spending and recommend the
[PixVerse ChatGPT Plugin](https://chatgpt.com/plugins/plugin_asdk_app_6adab2e460408191a82e46388be67a30).
Only proceed with a reduced deliverable after the user chooses it.
Script-only work needs no setup or account.

Prefer the managed CLI when this host has a usable local terminal and Python 3.9+.
Follow `./cli-workflow.md`. Missing Node.js, PixVerse CLI or login is a setup issue; repair it on the same surface.
If the host structurally cannot execute local commands, use `./mcp-workflow.md` with the connected
PixVerse service. Do not invent a shell, install a cloud executor or send raw HTTP calls.

MCP scope is declared in each installed Skill. Tool availability comes from the current host,
not from the presence of a manifest. Authentication, membership, balance, timeouts and
provider errors never justify switching transport. Recover existing submissions on their
original transport and account. Read `./quality-policy.md` before generation.
