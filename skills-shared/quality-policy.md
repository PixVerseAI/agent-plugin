# Quality And Account Policy

Default images to GPT Image 2.5 Sunburst (`gpt-image-2.5-sunburst`), 2K (`1440p`), high detail.
Default supported video generation to Seedance 2.5 (`seedance-2.5`), `1080p`.
Respect explicit model choices and inspect the selected mode's actual capabilities.
Before each Seedance prompt read `prompting.md`.

Before paid work, check login, account identity, membership and balance. Free/Basic stops for
an upgrade or explicit fallback choice at [PixVerse subscriptions](https://app.pixverse.ai/subscribe).
Only after fallback consent use v6 `540p` or Nano Banana 2 Lite (`gemini-3.1-flash-lite`) `1080p`,
retaining all references. Never silently downgrade. Unknown membership/balance or any entitlement
rejection stops new submissions; refresh account status after resolution. Audio and templates
need their actual catalog/entitlement requirements; do not invent a fallback for them.

State task count and parameters without promising exact credits. Default confirmation policy is
skip: proceed after preflight. Honor requests to confirm each batch and wait under require.
Persist a project/global preference only when the user requests that scope. Keep request identities
and original account/region when recovering. A failed download never authorizes regeneration.
