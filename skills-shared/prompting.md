# Generation Prompts

For images describe subject, composition, light, materials, requested text and reference roles.
Preserve the user's constraints. Default image detail is high at 1440p.

For Seedance 2.5 describe the scene, subject action, camera movement, timing and desired sound.
Keep a short single-beat clip focused on one coherent action. References must retain their actual
roles. Use the selected mode's capability schema for reference arrays and duration limits.
Do not add unsupported audio switches or copy parameters between CLI and MCP schemas.
Do not silently add a storyboard, another generation stage or a lower-quality model.
